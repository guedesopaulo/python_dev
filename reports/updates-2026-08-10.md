# Weekly Updates Report — 2026-08-10

## Summary

- **Security action needed:** `coverage` 7.15.4 fixes an HTML report XSS vulnerability and an LCOV injection flaw — upgrade immediately.
- **FastMCP 3.4.5/3.4.6** ships a critical JWT validation fix (Ed25519 JWKS) and trusted-proxy OAuth support; both patch releases are directly relevant to this project's MCP layer.
- **Ruff 0.16.x** is a breaking minor: the default rule set expanded from 59 to 413 rules and the formatter now processes Markdown files by default — expect new violations after upgrade.
- **MCP SDK v2** (stable, July 28) introduces a stateless protocol with no handshake, server/discover, and OAuth with RFC 9207; FastMCP 3.x tracks MCP v1 for now, so no urgent migration, but planning should start.
- **pydantic-settings 2.15.0** closes a symlink-traversal security issue in `NestedSecretsSettingsSource`; upgrade is straightforward and low-risk.

## New Community Practices

- **MCP SDK v2 is stable (July 28, 2026):** The official `mcp` Python SDK reached v2.0.0, introducing a stateless protocol (no initial handshake), `server/discover`, multi-round-trip requests, resolver dependency injection for tool mid-execution user input, OAuth with RFC 9207 issuer validation, and OpenTelemetry tracing by default. The v1.x line is now in security-only maintenance mode. FastMCP 3.x tracks the v1 protocol; roadmap for MCP v2 support should be monitored.
  — Source: <https://github.com/modelcontextprotocol/python-sdk/releases>

- **Ruff now formats Markdown code blocks by default (0.16.x):** Running `ruff format` on a project that includes `.md` files will now also format embedded Python snippets. Teams should validate this behavior and add `extend-exclude` entries in `ruff.toml` if Markdown docs should not be auto-formatted.
  — Source: <https://github.com/astral-sh/ruff/releases>

- **`uv init` now creates packaged (src-layout) projects by default (0.12.0):** This aligns with modern Python packaging best practices. Existing projects using `uv` should review whether their project structure matches the expected layout; this project already uses `src/`, so the impact is informational.
  — Source: <https://github.com/astral-sh/uv/releases>

- **FastAPI `app.frontend()` for local dev (0.141.0):** A new convenience method allows serving a static frontend alongside the API during `fastapi dev`, with `check_dir="auto"` auto-detection. While not directly needed for this API-only project, it simplifies future full-stack setups.
  — Source: <https://github.com/tiangolo/fastapi/releases>

- **`uv tool audit` for installed-tool vulnerability scanning:** Recent `uv` releases added `uv tool audit` to check globally installed tools for known CVEs. Useful for CI and developer machine hygiene checks.
  — Source: <https://github.com/astral-sh/uv/releases>

- **FastMCP trusted-proxy OAuth (3.4.6):** For MCP servers running behind corporate proxies, FastMCP 3.4.6 routes OAuth metadata and JWKS fetches through the configured proxy with custom CA support. This is relevant to any production deployment of the `/mcp` endpoint in cloud environments (`dev`/`qas`/`prod`).
  — Source: <https://github.com/jlowin/fastmcp/releases>

## Recommendations

Ordered by priority:

1. **[Immediate] Upgrade `coverage` to 7.15.4** — contains security fixes for XSS in HTML reports and injection in LCOV output. Run `uv lock --upgrade-package coverage` and re-run `make cov`.

2. **[High] Upgrade `fastmcp` to 3.4.6** — 3.4.5 fixes a JWT validation regression that silently rejects all tokens for Ed25519-keyed JWKS providers. If the `/mcp` endpoint uses token-based auth (it does via `BearerTokenMiddleware`), this is a correctness and security issue. Run `uv lock --upgrade-package fastmcp`.

3. **[High] Upgrade `pydantic-settings` to 2.15.0** — closes a symlink-traversal issue in `NestedSecretsSettingsSource`. Even if this feature isn't currently used, upgrading is low-risk and prevents future exposure.

4. **[Medium] Upgrade `fastapi` to 0.141.1** — picks up SSE and streaming response-model fixes. Patch-level risk is low. Run `uv lock --upgrade-package fastapi`.

5. **[Medium] Upgrade `uvicorn` to 0.52.1** — WebSocket close-handshake and write-flow fixes improve reliability; sequential worker restart in 0.51.0 already landed. The new `--http zttp` transport is experimental; do not enable in production.

6. **[Medium] Plan Ruff 0.16.x upgrade carefully** — the default rule set expansion is significant. Before upgrading, run `uv run ruff check --select ALL .` on the current codebase to preview the delta, then add explicit `ignore` entries to `ruff.toml` for rules that don't apply. Allow time to fix or suppress the new violations before merging.

7. **[Low] Upgrade `pre-commit` to 4.6.1** — minor bug-fix release; update is routine.

8. **[Future] Monitor FastMCP for MCP SDK v2 support** — the official MCP SDK has stabilized its v2 protocol. Track the FastMCP roadmap and plan a migration once FastMCP adds v2 support, as it introduces meaningful architectural improvements (stateless protocol, resolver DI, OTel tracing).
