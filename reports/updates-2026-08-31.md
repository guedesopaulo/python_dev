# Weekly Updates Report — 2026-08-31

## Summary

- **Security alert**: `fastmcp` 3.4.5 fixed a critical JWT verification bug where a single Ed25519 key in a JWKS caused `JWTVerifier` to reject every token; upgrade from `>=3.4.4` to `>=3.4.7` is strongly recommended.
- **Ruff 0.16.x is a breaking minor release**: the default ruleset expanded from 59 to 413 rules and Markdown formatting is now enabled by default — upgrading without a `pre-commit run --all-files` review will likely break CI.
- Six packages have updates available: `fastapi`, `fastmcp`, `pydantic-settings`, `uvicorn`, `ruff`, `mypy`, `coverage`, and `pre-commit`; none are major releases.
- The `FastMCP.from_fastapi()` pattern used in this repo is the community-recommended approach for 2026 and remains actively developed.
- The `uv`-based workflow and `ruff` + `mypy` toolchain already align with current Python ecosystem best practices.

## New Community Practices

- **FastMCP `from_fastapi()` is the recommended pattern** — the alternative `fastapi-mcp` library has not shipped a release since July 2025, while FastMCP is actively developed. This repo already uses the correct approach. ([mcp.directory comparison](https://mcp.directory/blog/fastmcp-vs-fastapi-mcp-vs-python-sdk-2026))

- **OAuth 2.1 is the MCP security standard for 2026** — MCP servers exposed beyond local-only use should implement transport-layer authentication with OAuth 2.1 token validation (not just static bearer tokens). FastMCP 3.4.x ships the `JWTVerifier` + JWKS support to enable this. ([Speakeasy guide](https://www.speakeasy.com/mcp/framework-guides/building-fastapi-server/))

- **Add explicit `operation_id` to AI-facing routes** — AI agents consume MCP tools by their operation name. FastAPI defaults to auto-generated IDs; setting explicit, stable operation IDs improves agent reliability and prevents churn when routes are refactored. ([apidog guide](https://apidog.com/blog/fastapi-mcp/))

- **Avoid blocking calls inside `async def` handlers** — any synchronous I/O (e.g. synchronous SQLAlchemy, `requests`, `time.sleep`) inside an `async def` route freezes the event loop and eliminates FastAPI's concurrency advantage. Use `asyncio.to_thread()` or `run_in_executor` for unavoidable blocking work. ([Medium: FastAPI under load 2026](https://medium.com/@2nick2patel2/fastapi-under-load-in-2026-pydantic-v2-uvloop-http-3-what-actually-moves-the-needle-74717b74e74e))

- **`uv lock` committed + `uv sync` in CI is the canonical workflow** — commit `uv.lock` for reproducible installs and use `uv sync` (not `uv install`) in CI. This repo does not have a `uv.lock` checked in; adding one would improve reproducibility. ([Real Python: uv guide](https://realpython.com/python-uv/))

- **Ruff's `ruff: ignore` comment is preferred over `# noqa`** — as of 0.16.0, Ruff supports `# ruff: ignore[RuleCode]` on the same line or the preceding line, which is more explicit than `# noqa`. Useful for the few suppressions this repo may need. ([Ruff 0.16.0 release](https://github.com/astral-sh/ruff/releases))

## Recommendations

Ordered by priority:

1. **[High — Security] Upgrade `fastmcp` lower bound to `>=3.4.7`** in `pyproject.toml`. The JWT Ed25519 JWKS fix in 3.4.5 is a critical correctness/security bug; even in `ENVIRONMENT=local` mode the MCP endpoint is auth-gated, making this upgrade important.

2. **[High — CI risk] Pin or audit `ruff` upgrade to 0.16.x before raising the constraint**. Run `uv run ruff check .` after bumping to verify no new violations fire. The 413-rule default set may flag code that currently passes; it is better to review than to discover failures in CI.

3. **[Medium] Update `mypy` pin from `==2.3.0` to `==2.3.1`**. This is a patch release with only bug fixes; the tight pin (`==`) means the fix is currently excluded.

4. **[Medium] Commit `uv.lock` to the repository**. Running `uv lock` generates a lockfile that makes installs fully reproducible across machines and CI. This is now the standard practice for `uv`-based projects.

5. **[Low] Upgrade remaining outdated packages** (`fastapi >=0.141.1`, `pydantic-settings >=2.15.0`, `uvicorn >=0.52.4`, `coverage >=7.16.0`, `pre-commit >=4.6.2`). These are straightforward patch/minor bumps with no breaking changes.

6. **[Low — Future] Consider adding explicit `operation_id` values to route decorators** as the MCP surface grows. Stable, human-readable operation IDs improve agent tooling and avoid regeneration churn.
