## New Community Practices

- **MCP `2026-07-28` protocol — sessionless requests**: The latest MCP spec supports stateless, self-contained requests over Streamable HTTP, enabling MCP servers to run behind load balancers without sticky sessions. FastMCP 4 already implements this. If deploying the MCP surface behind a reverse proxy or cloud load balancer, no additional server-side changes are needed.
  _Source: [github.com/jlowin/fastmcp/releases](https://github.com/jlowin/fastmcp/releases)_

- **MCP SDK security hardening (v2.2.0)**: HTTP redirects from MCP clients are now restricted to the same origin (cross-origin redirects fail with `MCPError`); idle Streamable HTTP sessions expire after 30 minutes; OAuth validation now checks issuer on all discovery paths. The new `AuthSettings.validate_token_resource` parameter lets servers verify that bearer tokens were issued specifically for them — relevant if the `/mcp` surface is ever exposed externally.
  _Source: [github.com/modelcontextprotocol/python-sdk/releases](https://github.com/modelcontextprotocol/python-sdk/releases)_

- **FastAPI `app.frontend()` for full-stack dev**: FastAPI 0.141.0 added `app.frontend(check_dir="auto")` to serve local frontend assets during `fastapi dev`, removing the need for a separate static file mount. Not immediately useful for this API-only starter, but worth knowing when adding a frontend.
  _Source: [github.com/tiangolo/fastapi/releases](https://github.com/tiangolo/fastapi/releases)_

- **Uvicorn HTTP/2 via `zttp` (opt-in, experimental)**: Uvicorn 0.53.0 adds opt-in HTTP/2 support: `uvicorn app:app --http zttp --http2`. Requires installing the `zttp` extra. The feature supports HTTP/2 over TLS with ALPN and cleartext prior knowledge, but WebSocket upgrades and h2c upgrades are not yet supported. Treat as experimental.
  _Source: [github.com/encode/uvicorn/releases/tag/0.53.0](https://github.com/encode/uvicorn/releases/tag/0.53.0)_

- **Ruff 0.16.7 preview rules (RUF077, RUF039)**: Ruff added `RUF077` (flags incorrect default values on method receivers) and `RUF039`/`RUF055` (recognizes `re.prefixmatch` and partial pattern matches). Enable with `preview = true` in `ruff.toml` to start using them. The archive installer now embeds checksums for verification.
  _Source: [github.com/astral-sh/ruff/releases/tag/0.16.7](https://github.com/astral-sh/ruff/releases/tag/0.16.7)_

- **Pydantic 2.13.x stabilisation**: The 2.13 line focused exclusively on bugfixes (default factories for private attributes, `ValidationInfo` in JSON validation, `RootModel` metadata, GC traversal). No new APIs requiring changes to existing Pydantic v2 code.
  _Source: [github.com/pydantic/pydantic/releases](https://github.com/pydantic/pydantic/releases)_

## Recommendations

Listed in priority order:

1. **Run `uv lock --upgrade-package uvicorn` to move to 0.53.0** _(medium priority)_.
   The IPv6 loopback proxy fix and WebSocket keep-alive fix are reliability improvements. The new HTTP/2 and `zuvloop` features are opt-in and require no code changes to pick up. Risk: low (no breaking changes flagged).

2. **Run `uv lock --upgrade-package coverage` to move to 7.16.1** _(low priority)_.
   Fixes a false-positive "missing" line when an irrefutable `case _:` block is excluded. Affects projects using `# pragma: no cover` on `match/case` — worth updating before the next coverage run to avoid noise.

3. **Run `uv lock --upgrade-package ruff` to move to 0.16.7** _(low priority)_.
   Patch-level fixes and minor rule additions. Zero risk; worth keeping in sync with the toolchain.

4. **Evaluate enabling `AuthSettings.validate_token_resource` before any external MCP exposure** _(medium-term, advisory)_.
   The current `BearerTokenMiddleware` validates tokens in `local` mode only (placeholder for cloud envs). If the `/mcp` mount is exposed beyond localhost, adopt the MCP SDK's new `validate_token_resource` and origin-scoped redirect protection from mcp 2.2.0 (already pinned).

5. **Consider enabling Ruff preview mode in CI** _(low priority, informational)_.
   Rules like RUF077 catch real bugs (wrong default on `self`/`cls` parameters). A `preview = true` flag in `ruff.toml` enables them without requiring a version bump.
